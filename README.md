## Featured Projects

### 1. [Security Hub](https://github.com/gusn9719/security_hub)

스미싱 문자와 의심 URL을 바로 열기 전에 위험도를 분석하고, 판단이 애매한 링크는 격리된 가상 브라우저에서 확인할 수 있도록 만든 한이음 ICT 드림업 2026 팀 프로젝트입니다.
사용자 피드백이 후속 분석에 반영되는 흐름을 갖추었으며, 프로젝트 아이디어와 전체 서비스 흐름을 구상하고 Flutter 앱과 FastAPI 영역의 구현·통합에 참여했습니다.

### 2. ReviewFit → BeautyLens

화장품의 평균 별점만으로는 피부타입에 따른 반응 차이를 보기 어렵다는 점에서 시작했습니다.
[ReviewFit](https://github.com/gusn9719/WebCrawling)에서는 OliveYoung 리뷰를 직접 수집하고 Musinsa/Coupang 외부 데이터를 통합한 뒤, 리뷰 전처리와 감성 분석 모델 학습·평가를 거쳐 같은 피부타입 리뷰의 부정 신호 비율로 상품을 확인하는 Streamlit 프로토타입을 구현했습니다.
이후 생성한 리뷰·추천 데이터를 [BeautyLens](https://github.com/gusn9719/beautylens-mvc)의 Oracle DB로 가져와 Spring MVC·MyBatis 웹 서비스에서 상품·리뷰와 피부타입 추천 등의 기능으로 연결했습니다.

### 3. [Gemma4 T17 RAG](https://github.com/gusn9719/gemma4-t17-rag-finetuning)

Tennant T17 영문 서비스 매뉴얼을 바탕으로 학습·평가용 QA 데이터셋을 직접 구성하고, text-only Gemma4 QLoRA fine-tuning과 Hybrid RAG 기반 기술문서 질의응답을 실험한 과제 프로젝트입니다.
데이터 분리와 검증부터 검색·답변 평가, failure analysis까지 과정을 기록했습니다.
